# Танковый турнир

Сайт для подсчёта очков взводного турнира: таблица лидеров, две ступени, ставки.

- Зрители: `https://<сайт>.vercel.app/` — результаты обновляются сами каждые ~4 сек.
- Ведущий: `https://<сайт>.vercel.app/?admin` — ввод опыта, при первом заходе спросит пароль (`ADMIN_KEY`).

## Деплой на Vercel

1. Импортировать репозиторий в Vercel (Framework: Other, без сборки).
2. Storage → Create Database → **Upstash for Redis** (бесплатно) → Connect к проекту.
3. Settings → Environment Variables → добавить `ADMIN_KEY` = любой пароль.
4. Redeploy.

Без сервера (открыть `index.html` локально) сайт тоже работает, но только у тебя в браузере.
